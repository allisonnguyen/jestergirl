Portrait

Assignment

For this assignment, the goal was to create an illustration of my character using vector images in Adobe Illustrator.

Final Submission

Process

I chose a muted color palette to reflect the medieval time period my character is set in. I used only the pen tool or already existing shapes to create my illustration.

Reflection

This was my first time using Adobe Illustrator, and it had a bit of a learning curve. At first, I struggled with how I wanted the character to be designed. Originally, I sketched out my character and I wanted her to have a more dynamic pose. But after I started to translate my sketch to an vector illustration, I realized that the art style I picked wasn't the best approach. I switched to a full frontal view instead of the 3/4 view that I had originally picked, and simplified the design a lot. This version still gets the essence of the character across, and I think it turned out better than the project I had started with.
