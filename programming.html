Programming

Assignment

The goal of this assignment was to design and create a website using HTML and CSS. My website should have at least 5 pages with at least 2 hyperlinks to choose from on each page. Each page should be inserted with a different project I've completed over the course of the semester. Additionally, I described my character's transformative qualities with the interactive sketch using the p5.js library.

Final Submission

Process

For the website, I wanted to create something that was in line with the medieval time period. I picked colors for the website that resembled parchment paper, like you might find on a map. I also chose a font that resembled latin manuscripts that I have seen at exhibits in the Met Cloisters. I also wanted the website to be slightly responsive, so I made the navigation bar change positions from the left to the bottom if the page size became too small. For the p5.js sketch, it was supposed to reflect my character's powers, which were illusions and tricks. I felt that the best way to illustrate this was to create many multicolored bubbles that change size and disappear, which can be disorienting and also enticing. For the interactive element, I wanted it to resemble a bright explosion that she might use to trick her audience.
