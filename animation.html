Animation

Assignment

The goal for this project was to create a 10 second animation in After Effects (at 29.97 fps) based on our character.

Final Submission

Process

One of the requirements was to add effect keyframes, so I added some wave warping for the collar's motion, and bubbles in the background. I wanted the animation project to resemble the p5.js sketch that I had made earlier, so I had the bubbles change color. I also added the white stars that I had in the programming assignment.

Reflection

I have used Adobe After Effects before, so it was fun to refamiliarize myself with the tools and process. In the future, I would like to try more complicated animations, like moving the arms or the hat.
